# Amuse bouche: design preview

Static demonstration only. Products, prices and AI illustrations are unapproved demo content. No orders, payments, forms, personal data, Laravel, CRM or API.

GitHub Pages publishes the root of the main branch. Keep the base path `/amuse-bouche-preview/`, every HTML robots meta `noindex,nofollow`, and robots.txt crawlable. `.nojekyll` preserves Nuxt assets.

To update, regenerate the isolated static export from the approved storefront snapshot, inspect every output file, verify desktop/mobile and nested-route reloads, then commit only the checked static output to this repository. Do not upload the main project, env files, databases or internal reports.
